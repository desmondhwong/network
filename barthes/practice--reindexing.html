Reindexing a question

Reindexing changes the organizing coordinates of a question. A problem framed as “How can we increase use?” might become “Who finds entry difficult?” or “What use do our measures miss?” The object remains related, but the categories guiding attention change.

A useful reindexing changes what counts as evidence or success. If a library measures only loans, a framing centered on time spent studying makes different activity visible. A shift toward accessibility may bring transport, communication, and opening hours into the inquiry.

The source describes this operation as jumping between manifold regions. The observable act is a change in framing. We can inspect the old question, the new question, and the consequences without claiming to observe an internal geometric jump.

Ask for three reframings, each naming one assumption it drops and one burden it creates. A new coordinate system may reveal one problem while obscuring another. Lenses and parallax help compare these tradeoffs.

Reindexing can interrupt a recursive loop. When successive answers elaborate the same framework without improving it, change the comparison or return to a concrete case. The purpose is to restore contact with the inquiry, not to keep novelty flowing indefinitely.
